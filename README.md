# SET / mai Multi-Timeframe MACD Scanner — Report

Static HTML report published with GitHub Pages.

- `index.html` — scan summary dashboard (light theme), grouping results by
  pullback / turnaround groups plus 3×3 chart pages
- `chart_3x3_*.png` — chart images referenced by the report (14 files, ~10.7 MB)
- `scan_summary_table.csv` — underlying scan table

## Rebuild

Generated by `../scan_macd_screener.py` + `../generate_html_report.py`
(output directory = this folder). After regenerating, commit and push:

```bash
git add -A && git commit -m "update scan <date>" && git push origin main
```
